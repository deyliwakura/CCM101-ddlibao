# Mission 7: The Cloud Operations Engineer

## Mission Overview

This laboratory activity focuses on monitoring Linux system resources, deploying an Nginx web server using Docker, generating HTTP traffic, and analyzing application logs and container metrics.

## Objectives

- Monitor RAM, disk storage, and CPU activity.
- Deploy an Nginx container.
- Generate successful and failed HTTP requests.
- Inspect application logs and container resource usage.
- Document monitoring results in Markdown.

## Monitoring Commands Executed

- `free -h` — checks memory information.
- `df -h /` — checks root filesystem storage.
- `top` — monitors CPU activity and running processes.
- `docker ps` — lists running containers.
- `curl` — sends HTTP requests to the web server.
- `docker logs client-website` — displays application logs.
- `docker stats` — displays live container resource usage.

## Skills Learned

I practiced Linux system monitoring, Docker container deployment, HTTP traffic simulation, application log analysis, and resource monitoring. I also improved my technical documentation and GitHub portfolio skills.
