# Mission Reflection

## Reflection

Completing the Multi-Cloud Explorer mission helped me understand how different cloud platforms work and how they can be used in real-world situations. Among the three platforms, **AWS impressed me the most** because it offers a wide range of cloud services and provides flexible options for computing, storage, networking, databases, and other IT needs. I also learned that AWS, Azure, and GCP are not completely different from each other because they provide similar core services. For example, all three platforms offer virtual machines, cloud storage, networking, databases, identity management, and tools for application development.

I learned that **business requirements greatly influence cloud platform selection**. A company should not simply choose a cloud provider because it is popular. Instead, it should consider its budget, existing technologies, security requirements, scalability, location, performance, and type of workload. For example, Microsoft Azure may be a better choice for a company that already uses Microsoft technologies, while Google Cloud can be a good option for organizations focused on artificial intelligence, machine learning, and data analytics.

Acting as a **Cloud Solutions Consultant** helped me practice analyzing business situations and recommending an appropriate cloud platform. I learned that a consultant needs to understand both the technical capabilities of cloud services and the actual needs of the client. The recommendation should be based on the client's requirements rather than personal preference.

This mission also improved my **GitHub Cloud Computing Portfolio**. I added research about AWS, Azure, and GCP, compared their services, created a decision matrix, documented Linux server investigation, and identified equivalent cloud services for migrating a Linux server. Overall, this mission improved my knowledge of cloud computing and gave me practical experience in documenting and presenting cloud solutions.
