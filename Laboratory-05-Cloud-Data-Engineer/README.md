# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on cloud object storage using MinIO. I deployed MinIO using Docker and created a bucket for storing files.

## Objectives

- Understand Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create a storage bucket.
- Upload a file to the bucket.

## Tools Used

- KillerCoda
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Deploying containers with Docker
- Using environment variables
- Accessing services through ports
- Creating cloud storage buckets
- Uploading objects to storage
