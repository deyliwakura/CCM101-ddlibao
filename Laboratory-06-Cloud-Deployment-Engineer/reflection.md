# Mission 6 Reflection

The docker-compose.yml file made the cloud engineer's job easier because it allowed multiple containers to be configured in one file. Instead of running many Docker commands separately, I could use one command, `docker-compose up -d`, to deploy the Nextcloud application and MariaDB database together. YAML is sensitive to indentation, so an incorrect indentation or using tabs instead of spaces can cause errors and prevent the services from starting correctly. Environment variables such as `MYSQL_PASSWORD` are important because they provide the configuration information needed for Nextcloud to connect to the MariaDB database. I felt that deploying Nextcloud in a few minutes was convenient and interesting because Docker Compose made the deployment process faster by starting the application and database together. Since Mission 1, my understanding of cloud computing has improved because I have learned more about infrastructure, containers, storage, databases, and deployment. This mission helped me understand how multiple services can work together as one application and how automation can make cloud deployment easier.
